# docs.tsvsheet.remark

Public documentation for [`tsvsheet/tsvsheet.remark`](https://github.com/tsvsheet/tsvsheet.remark) — the [tsvsheet](https://github.com/tsvsheet/tsvsheet) remark and markdown-it plugins: render fenced `sheet` blocks as computed tables via the embedded WebAssembly engine.
